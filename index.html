Why isn't this "live"?

Published pages run in a sandbox that only allows outbound network calls to a short list of script hosts — direct fetches to IESO, AESO, Hydro-Québec, etc. are blocked for security, so no page built this way can poll them in real time. A truly live version needs a small backend you host yourself (e.g. a Claude Code project) that pulls each utility's public report and re-serves it as JSON with CORS enabled; this page could then poll that backend. Happy to build that backend if you want it.
